# ADR 0008：低风险任务自动派单与 PR 自动修复

- 状态：已接受
- 日期：2026-10-22

## 背景

维护者希望后续小修复自动交给机器人，减少重复勾选和派单。[ADR 0007](0007-bot-collaboration.md) 的审查机器人只读职责需要局部调整；人工合并与高风险升级评审继续有效。

## 决策

- CodeRabbit 可通过原生 Triage Auto-fix 规则修改符合条件的 PR 工作分支；规则限定 DockDSM、低风险和低影响范围，按[操作约定](../bot-automation.md)设置。规则自动修复与 PR Walkthrough 的 Autofix 控件属于不同入口，不保证复选框视觉状态同步。
- 维护者可通过专用 Issue 表单预授权文档或测试小任务。Actions 核验作者及触发者当前写权限、标签、明确文件清单和授权后加上 jules 标签；不自动将所有公开 Issue 派给机器人。
- 一个分支同时只有一个写入者。Jules 负责 Issue 实现；Codex 负责高风险修改和最终复核；CodeRabbit 只在其它写入者交接后承担符合规则的小修复。禁止机器人递归创建任务或互相派单。
- 机器人可在任务范围内追加提交和创建 PR，不自动合并、发布、强推、绕过保护或降低测试强度；运行时磁盘、生产 QEMU、ARM、安全和发布变更保留人工处理。
- 每次 CodeRabbit Auto-fix run 最多两轮。试用、可用额度和供应商计费检查独立生效；轮数不是月度费用上限，不为自动化开启付费 add-on。

## 后果

按规则减少重复操作，但标签、模型风险分级和任务指令不是文件级权限隔离。Triage 文件筛选是任一文件命中，不能证明整个 PR 仅改文档。维护者必须审阅最终 diff；外部执行与凭据能力的未验收部分登记 [RISK-008](../RISK_REGISTER.md#risk-008p1机器人自动写入与自动派单端到端未验收)。

## 替代方案

- 所有 PR / Issue 无条件开启：超出小修复范围，拒绝。
- Actions 使用 PAT 冒充维护者发送 autopilot 评论：原生规则可用，不采用。
- 继续每次人工勾选：保留为高风险 PR 中单个安全反馈的处理方式。
